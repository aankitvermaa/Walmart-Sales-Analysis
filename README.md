# Walmart-Sales-Analysis
Data analysis project on Walmart sales performance using Python, SQL, and Power BI. Includes data cleaning, exploratory analysis, dashboard visualization, and insights on sales trends.

# 🛒 Walmart Sales Analysis

This project explores Walmart's sales data to uncover trends, patterns, and insights using **Python**, **SQL**, and **Power BI**.

---

## 📊 Project Overview
The goal of this project is to analyze Walmart’s sales performance across stores and departments, understand the impact of holidays, and identify key factors driving sales variations.

---

## 🧰 Technologies Used
- **Python** → Data cleaning, aggregation, visualization  
- **SQL** → Querying, joins, aggregations  
- **Power BI** → Interactive dashboards and reporting 

---

## 📂 Project Structure
```
walmart-sales-analysis/
```

---

## 🧪 Key Insights
- **Store Type A** generated the highest overall sales across all periods.  
- **Holiday weeks** showed a **20–25% increase in sales** compared to non-holiday weeks.    
- Seasonal peaks observed in **November–December**, aligning with major holidays.

---

## 🖥 Power BI Dashboard
The Power BI dashboard highlights:
- Monthly and yearly sales trends  
- Store-wise and department-wise analysis  
- Holiday vs. non-holiday sales comparison  
- KPIs and performance metrics  

📍 *Dashboard file:* `powerbi_dashboard/dashboard.pbix`
